# Uriel website

Static site for the Uriel group: Uriel Properties, Uriel Construction, Uriel Oil and Gas, Uriel Farms and Uriel Integrated Ventures.

- `index.html` holds the whole site. Pages are switched with links like `#properties`, `#construction`, `#oilgas`, `#farms`, `#ventures` and `#contact`.
- `img/` holds the project photos, named by project (for example `banana-1.jpg`).
- Deployed on Cloudflare Pages from the `main` branch. No build step: the output directory is the repo root.
